# Negative exponential of the Laplace approximation

Negative exponential of the Laplace approximation

## Usage

``` r
g(x, beta, se, tau, psi, r, k, R)
```

## Arguments

- x:

  Input

- beta:

  Vector of effect size estimates.

- se:

  Vector of the standard errors of the effect size estimates.

- tau:

  Parameter tau.

- psi:

  Parameter psi (not used).

- r:

  Parameter r.

- k:

  Model size.

- R:

  LD matrix.

## Value

Value.
