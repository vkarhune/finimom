# Beta-binomial density.

Beta-binomial density.

## Usage

``` r
dbb(x, p, a, b, log = TRUE)
```

## Arguments

- x:

  Function argument.

- p:

  Parameter p.

- a:

  Parameter a.

- b:

  Parameter b.

- log:

  Whether log-density is returned – defaults to TRUE.

## Value

(Log-)density value.
