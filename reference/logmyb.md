# Log-marginal likelihood for the data.

Log-marginal likelihood for the data.

## Usage

``` r
logmyb(x, se, tau, psi, r, k, R, gval)
```

## Arguments

- x:

  Vector of effect sizes.

- se:

  Vector of standard errors.

- tau:

  Parameter tau.

- psi:

  Parameter psi (not used).

- r:

  Parameter r.

- k:

  Model size.

- R:

  LD matrix.

- gval:

  Value of g.

## Value

Value.
